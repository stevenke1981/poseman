# 姿勢人偶 PoseMan

網頁版 3D 擺姿勢人偶參考工具，以 Three.js 程序化建構人體模型，可供繪圖、動畫前期參考使用。

## 功能

- **拖曳擺姿勢**：點選人偶關節後直接拖曳旋轉，或用右側面板 X/Y/Z 滑桿微調
- **姿勢範本**：站立、行走、跑步、坐下、揮手、思考
- **多人物**：可加入／移除多個角色，男／女體型，支援切換性別（保留目前姿勢）
- **預覽模式**：隱藏所有 UI 與關節指示球，得到乾淨畫面
- **匯出參考圖**：將目前畫面輸出為 PNG（檔名含時間戳）
- **自動儲存**：場景（人物、性別、姿勢、格線開關）自動存入 `localStorage`，重新整理不丟失
- **視角控制**：空白處拖曳旋轉視角、滾輪／雙指縮放，可一鍵重設視角

## 操作說明

| 動作 | 效果 |
| --- | --- |
| 點選人偶關節 | 選取關節（橘色線框球標示） |
| 關節上拖曳 | 旋轉該關節 |
| 空白處拖曳 | 旋轉視角 |
| 滾輪／雙指 | 縮放 |
| 預覽模式 → 匯出參考圖 | 輸出乾淨的 PNG 參考圖 |

## 開發

```bash
npm install
npm run dev      # http://localhost:5173
```

## 建置

```bash
npm run build    # 輸出至 dist/
npm run preview  # 本機預覽建置結果
```

## 技術

- [Three.js](https://threejs.org/)（r166）
- [Vite](https://vitejs.dev/) 5
- 無後端、無其他執行期依賴；人偶以程序化幾何體（球體／膠囊體）建構，幾何與材質跨人物共享

## 檔案結構

```
src/
  main.js       # 場景、控制器、UI 事件、持久化、匯出
  mannequin.js  # 程序化人偶建構（關節階層、共享幾何快取）
  poses.js      # 姿勢範本（歐拉角，單位：度）
  style.css     # UI 樣式
```
